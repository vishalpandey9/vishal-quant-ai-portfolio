# AI-Powered Student Placement Predictor & ATS Resume Scanner

Built by **Vishal Pandey** (B.Tech CSE)

## Features
1. **Random Forest Placement Classifier (`Scikit-Learn`):** Predicts campus/off-campus placement probability based on CGPA, Internships, Technical Projects, Quantitative Aptitude, and Coding scores.
2. **Automated ATS Resume Scanner:** Evaluates resume text against any pasted Job Description to calculate an instant ATS match percentage and highlight missing technical keywords.

## How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
