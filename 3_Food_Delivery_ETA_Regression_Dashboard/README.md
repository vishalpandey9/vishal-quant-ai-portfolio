# End-to-End Food Delivery Time Prediction Dashboard

Built by **Vishal Pandey** (B.Tech CSE)

## Overview
A supervised Machine Learning Regression application (`RandomForestRegressor`) deployed via **Streamlit** that predicts real-time food delivery Estimated Time of Arrival (ETA) in minutes using delivery distance, restaurant preparation time, traffic density, weather conditions, and rider ratings.

## How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
